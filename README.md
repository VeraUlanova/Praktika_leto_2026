# Praktika_leto_2026

## Кейс-задача № 3
Адаптируйте задание под организацию, на базе которой вы проходите практику. 
"Интеграция искусственного интеллекта в бизнес-процессы" может быть адаптирована под любую организацию, которая хочет улучшить свои бизнес-процессы и повысить эффективность работы с помощью технологий искусственного интеллекта.
Организация: Предположим, что мы работаем в компании, которая занимается разработкой программного обеспечения. Наша задача - интегрировать искусственный интеллект в бизнес-процессы компании для улучшения качества продукта и повышения эффективности работы команды.
Задача: 
•	Анализ текущих бизнес-процессов компании и выявление тех, которые могут быть улучшены с помощью искусственного интеллекта.
•	Выбор подходящих технологий искусственного интеллекта для каждого из выявленных бизнес-процессов.
•	Разработка и внедрение решений на основе искусственного интеллекта для каждого из бизнес-процессов.
•	Обучение сотрудников компании работе с новыми технологиями и их интеграция в повседневную работу.
•	Мониторинг и анализ результатов внедрения искусственного интеллекта в бизнес-процессы компании.


Одним из самых интересных и требующих автоматизации бизнес-процессов в компании оказался юридический анализ договоров.

## Юридический анализ договоров.

Для этого было предложено разработать прототип AI-помощника юриста. То есть реализовать сценарий:
«AI-анализатор договоров»:

## Входные данные
Текст договора в виде файла .pdf, .docx или .txt

## Обработка
ИИ анализирует:
•	стороны;
•	предмет договора;
•	стоимость;
•	сроки;
•	ответственность;
•	порядок оплаты;
•	порядок расторжения;
•	штрафные санкции;
•	форс-мажор;
•	подсудность;
•	персональные данные;
•	иные существенные условия.

## Результат:
ИИ-анализ договоров:
- определяет тип договора;
- выделяет ключевые условия;
- ищет потенциально невыгодные положения;
- выявляет юридические риски;
- сравнивает документ с корпоративным шаблоном;
- предлагает варианты корректировки;
- формирует краткий отчёт для юриста. в формате .md


## Для решения задачи используется смешанный подход:
- Бесплатные API (Google Gemini Flash) — для глубокого семантического анализа, потому что локальные модели часто "тупят" на юридических текстах.
- Локальные NLP-библиотеки (spaCy, re) — для быстрого извлечения дат, сумм и имен.

## Как это работает
- Извлечение текста — функция extract_text_from_file универсально читает .docx, .pdf и .txt.
- Локальный NLP-анализ — использует spaCy с моделью для русского языка, чтобы быстро вытащить даты, суммы и названия организаций без затрат API.
- AI-анализ через Gemini — каждый бизнес-пункт (тип договора, ключевые условия, риски) отправляется отдельным запросом к модели. Это сделано для лучшей фокусировки — модель получает конкретный вопрос и дает структурированный ответ.
- Сравнение с шаблоном — если у тебя есть корпоративный шаблон, система сравнит его с текущим договором. Если нет — использует встроенный образцовый шаблон.
- Формирование отчета — все результаты собираются в Markdown-файл, который юрист может открыть в любом редакторе.

## Важные моменты.
- Почему Gemini, а не ChatGPT? — У Google Gemini есть бесплатный тариф с достаточно большим контекстом (до 1 млн токенов), и он отлично работает с русским языком.
- Можно ли заменить на локальную модель? — Да, но качество будет ниже. Можно использовать LLaMA 3 через Ollama, но для этого нужен мощный компьютер.

Код для Ollama приводится в отдельном файле.
#### Безопасность — код не отправляет данные на сервер, кроме запросов к Gemini это стоит учитывать, так как коммерческие данные нельзя передавать в облачные API.
